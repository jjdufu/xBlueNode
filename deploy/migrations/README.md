# 数据库编号迁移规范

禁止多人直接修改已有迁移文件。新增模块表结构必须按以下编号段新增独立幂等 SQL 文件（`CREATE TABLE IF NOT EXISTS`）：

| 编号段 | 所属模块 | 说明 |
| :--- | :--- | :--- |
| `001_init_core.sql` | 基础底座 | 核心超图 `hg_*` 与基础 `xb_*` / `ax_*` 表 |
| `002_*.sql` | `AxHub` | 连接器、数据集注册、列画像与同步作业表 |
| `003_*.sql` | `AxGraph` / `xBlueStudio` | 时序指标、血缘追踪与数据映射规则表 |
| `004_*.sql` | `AxFlow` | DAG 执行记录、步日志、人工审批与 API/MCP 发布表 |
| `005_*.sql` | `AxSim` / `xBlueView` | 多方案对比、孪生驾驶舱与全格式出品任务表 |
| `006_*.sql` | `AxGuard` | 用户、角色、行/列脱敏策略与审计日志表 |
